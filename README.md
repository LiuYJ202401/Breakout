## Breakout程序设计基础大作业

**注：本项目采取C++17标准，使用EasyX图形化库**

<hr>

### 主要文件

1.```Breakout.cpp```是```main()```函数所在的文件，负责整体的循环与绘制。

2.```BasicSettings.h```和```BasicSettings.cpp```是所有文件都会```include```的，包含依赖库、通用常量等基础信息。

3.```GameManager```类是整个游戏的中枢，根据状态与输入，调用不同的运行函数和绘制函数；包括主菜单界面、配置文件界面、残局界面的切换以及进入游戏。

4.```aGame```类控制单局游戏，由```GameManager```控制创建实例，被输入配置文件、残局等信息而创建，完成一局游戏的功能；可以使用```Ball```、```Baffle```、```Map```等类构造、运行游戏。

5.```Button```类是单个按钮，完成按钮的创建、绘制与交互检查。

6.```Map```管理控制```Brick```，形成地图.

<hr>

### 游戏流程

1.进入游戏，首先进入*主菜单*，有*开始游戏*、*配置文件*、*残局*、*退出游戏*四个按钮。

2.点击*配置文件*可修改当前的配置、创建新配置或返回*主菜单*。*残局*同理。

3.点击*退出游戏*则退出游戏。

4.点击*开始游戏*，依据*残局*>*配置文件*的优先级创建新一局游戏，进行游戏，结束后返回*主菜单*。

5.游戏进行中可暂停，暂停时可以继续游戏或创建残局。

<hr>

### 游戏操作

1. 按ad或←→控制挡板移动。

2. 小球初始时静止，按空格发球。

3. 游戏中按P暂停。

4. 游戏中，按C可跳过当前关卡，按B可增加血量（作弊功能，调试用）。

5. 游戏过程中，如果小球卡住，按R来脱困。
